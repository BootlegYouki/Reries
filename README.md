# Setsu

A personal finance tracker for iPhone and Android. Everything stays on your phone: no account, no cloud sync.

Download the latest build from [Releases](../../releases/latest):

- **Android:** `Setsu-<version>.apk`. Open it on your phone and allow installing from this source.
- **iPhone:** `Setsu-<version>-unsigned.ipa`. It is not signed, so sign and install it with a sideloading tool such as SideStore or AltStore. Needs iOS 26 or later.
