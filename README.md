# Reries

Releases of my apps for iPhone and Android. Each app keeps everything on your phone: no account, no cloud sync.

| App | What it is | Platforms |
|---|---|---|
| **Setsu** | Personal finance tracker: budgets, expenses, goals and debts | iPhone, Android |
| **Tabi** | Applicant manager for overseas worker deployment: requirements, cash advances, sub-agents, passport appointment dates | iPhone |

## Download

Open [Releases](../../releases) and pick the newest release of the app you want. Releases are named after the app, for example "Setsu 1.1.1" or "Tabi 1.0.0".

- **Android:** `<App>-<version>.apk`. Open it on your phone and allow installing from this source.
- **iPhone:** `<App>-<version>-unsigned.ipa`. It is not signed, so sign and install it with a sideloading tool such as SideStore or AltStore. Needs iOS 26 or later.

## Updates in KSign

Add this source in KSign (or any app that reads AltStore sources) to see new versions and install them without coming back here:

```
https://raw.githubusercontent.com/BootlegYouki/Reries/master/source.json
```
